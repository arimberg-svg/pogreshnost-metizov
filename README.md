# Калькулятор погрешности по метизам

Две отдельные пропорции для акта о расхождении. Это не одно списание.

- Вес: 5 из 100, это 50 г на 1 кг.
- Штуки: 12 из 100, это 12 штук на каждые 100.
- Сумма строки только для справки, на пропорцию не влияет.

Калькулятор: https://arimberg-svg.github.io/pogreshnost-metizov/
